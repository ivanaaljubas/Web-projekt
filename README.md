# Web stranica za recepte

Ova web aplikacija omogućuje pregledavanje, lajkanje i komentiranje recepata, kao i upravljanje receptima putem administratorskog sučelja.

## Funkcionalnosti
- Prikaz recepata s detaljnim informacijama (naslov, opis, sastojci, vrijeme pripreme, slika)
- Lajkanje i komentiranje recepata (samo za prijavljene korisnike)
- Administratorska stranica za dodavanje i brisanje recepata
- Filtriranje aktivnosti korisnika (lajkovi i komentari)

## Tehnologije
- HTML
- CSS
- JavaScript
- PHP
- Baza podataka

## Napomena
Ovaj projekt je izrađen u edukativne svrhe i predstavlja osnovnu verziju sustava za upravljanje receptima.
